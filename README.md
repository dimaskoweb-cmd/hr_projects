# hr_projects

Конвейер отклика на вакансию: вакансия на входе, в ответ карточка компании и шкала в чате, A4 PDF для HR.

## Конвейер

1. Вакансия отправляется в чат.
2. В чате собирается всё о компании: карточка, шкала ценностей, тепловая карта, SWOT, рейтинг надёжности. Эта часть только для кандидата.
3. Из тех же данных собирается A4 PDF для HR: мост «задача компании → мой опыт → что это даёт компании», карта совпадения с требованиями, SWOT интеграции. Данных о компании (рейтинги, суды, надёжность) в PDF нет.
4. Сопроводительное письмо выдаётся отдельным текстовым окном для копирования.

## Запуск

```bash
python3 tools/build_pdf.py examples/demo.json -o out/demo.pdf
```

Нужны Python 3 и `reportlab`. Шрифт с кириллицей ищется в `/usr/share/fonts/truetype/dejavu`, другой каталог задаётся переменной `HR_FONT_DIR`.

Генератор не соберёт PDF, если в данных:
- упомянут уровень английского C2 (по правилу проекта указывается C1/B2);
- есть пустой раздел SWOT или неверная оценка совпадения;
- не заполнены обязательные поля шапки.

## Карточка компании (Checko API)

```bash
python tools/checko_fetch.py 7707049388            # карточка + надёжность (2 запроса)
python tools/checko_fetch.py 7707049388 --extra    # + суды, приставы, банкротства, проверки, Федресурс (7 запросов)
```

Ключ: файл `.env` в корне проекта со строкой `CHECKO_API_KEY=...` (образец — `env.example`) или переменная окружения. Результат сохраняется в `local/checko/` (не попадает в репозиторий). Бесплатный тариф — 100 запросов в сутки. Только стандартная библиотека Python. Тесты: `python -m unittest discover -s tests`.

## Формат данных (JSON)

| Раздел | Содержимое |
|---|---|
| `meta` | `candidate`, `candidate_title`, `position`, `company`, `date` (ГГГГ-ММ-ДД); необязательно `contacts`, `demo` |
| `thesis` | `employer_seeks` — что ищет работодатель; `candidate_value` — чем кандидат полезен |
| `bridge` | список из 3–4 строк: `task`, `experience`, `effect` |
| `heatmap` | список требований: `requirement`, `importance`, `match` (0–5), `basis` |
| `swot` | `S`, `W`, `O`, `T` — списки по 2–5 пунктов |
| `closing` | необязательная финальная фраза |

Допустимая `importance`: Критично, Важно, Средне, Второстепенно.

## Расчёт совпадения

Совпадение = сумма (вес × оценка) / сумма (вес × 5). Веса: Критично ×4, Важно ×3, Средне ×2, Второстепенно ×1.

Шкала оценки:

| Оценка | Смысл |
|---|---|
| 5 | Прямой подтверждённый опыт |
| 4 | Очень близкий опыт |
| 3 | Релевантная профессиональная база |
| 2 | Частичная применимость |
| 1 | Слабая связь |
| 0 | Подтверждения нет |

## Правила

- Только подтверждённые факты: источник — документы проекта и резюме кандидата. Нет подтверждения — оценка 0 или пункт не включается.
- Английский — C1/B2.
- Секреты (ключ Checko и любые другие) хранятся только в локальном `.env`, в репозиторий и в чат не отправляются.

## Открытые решения

- Как отдавать PDF по уникальной ссылке без открытого списка файлов в репозитории. Пока `*.pdf` в `.gitignore`, реальные отклики сюда не загружаются.
- Шкала ценностей и веса критериев: донастройка после технической части.
